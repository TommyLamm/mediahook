# 建立 iPhone 捷徑

會做兩個捷徑：

- **MediaHook 下載**：圖片、影片存進相簿，文案拷貝到剪貼板
- **MediaHook 抽音訊**：把影片的聲音存成 m4a，放進「檔案」App

`.shortcut` 檔需要 Apple 簽章，沒辦法直接提供可匯入的檔案，請照下面步驟建立一次。
動作名稱後面括號是英文版名稱，在動作搜尋欄打中文或英文都找得到。

## 運作方式

```
分享 → MediaHook 下載
  1. POST /api/jobs?wait=20     伺服器最多等 20 秒，大部分貼文這次就會完成
  2. 還沒完成就 GET poll_url    每次再等最多 20 秒，最多重複 15 次
  3. 完成後逐一下載 items        圖片/影片 → 相簿，音訊 → 檔案 App
  4. 文案拷貝到剪貼板、跳通知
```

伺服器回應（JSON）中會用到的欄位：

| 欄位 | 說明 |
|---|---|
| `status` | `running`、`done`、`failed` 三種 |
| `message` | 給人看的訊息，完成時是「已完成：2 張圖片、1 部影片」，失敗時是錯誤原因 |
| `poll_url` | 還沒完成時，用這個網址繼續查 |
| `items` | 檔案清單，每個有 `type`（`image`、`video`、`audio`）與 `url` |
| `caption` | 貼文文案 |
| `share_text` | 文案＋作者＋原始連結，適合直接貼上 |

## 建立「MediaHook 下載」

打開「捷徑」App → 右上角 **＋** → 命名為「MediaHook 下載」，依序加入以下動作。

### 設定輸入

1. 點捷徑名稱下方的 **ⓘ（詳細資訊）**，打開 **在分享表單中顯示**。
2. 最上方會出現「從**分享表單**接收**任何**輸入」：
   - 把類型改成只勾 **URL** 和 **文字**（抖音、小紅書分享出來的是一段文字，伺服器會自己找出網址）
   - 「如果沒有輸入」選 **取得剪貼板**：這樣在主畫面直接點捷徑，會改抓剪貼簿裡的連結

### 動作清單

**① 文字**（Text）
- 內容：`Bearer ` 後面接你的 API 金鑰（`Bearer` 與金鑰中間有一個空格）

**② 設定變數**（Set Variable）
- 變數名稱：`授權`，值：上一步的「文字」

**③ 取得 URL 內容**（Get Contents of URL）
- URL：`https://dl.gyke.net/api/jobs?wait=20`
- 展開「顯示更多」：
  - 方法：**POST**
  - 標頭：新增 `Authorization`，值選變數 **授權**
  - 要求本文：**JSON**，新增兩個「文字」欄位：
    - `url` → 變數 **捷徑輸入**（Shortcut Input）
    - `mode` → `auto`

**④ 設定變數**
- 變數名稱：`回應`，值：**URL 的內容**

**⑤ 重複**（Repeat）15 次，裡面放：

- **取得辭典值**（Get Dictionary Value）：取得 `status` 的值，來源 **回應**
- **如果**（If）「辭典值」**是** `running`：
  - **取得辭典值**：取得 `poll_url` 的值，來源 **回應**
  - **取得 URL 內容**：URL 為上一步的「辭典值」，方法 **GET**，標頭 `Authorization` = 變數 **授權**
  - **設定變數**：`回應` ＝ **URL 的內容**
- **結束如果**

**⑥ 取得辭典值**：取得 `status` 的值，來源 **回應**

**⑦ 如果**「辭典值」**不是** `done`：
- **取得辭典值**：取得 `message` 的值，來源 **回應**
- **顯示提示**（Show Alert）：內容為上一步的「辭典值」
- **停止此捷徑**（Stop This Shortcut）
- **結束如果**

**⑧ 取得辭典值**：取得 `items` 的值，來源 **回應**

**⑨ 重複每一個**（Repeat with Each）項目在「辭典值」中，裡面放：

- **取得辭典值**：取得 `url` 的值，來源 **重複項目**
- **取得 URL 內容**：URL 為上一步的「辭典值」（方法 GET，不用加標頭）
- **取得辭典值**：取得 `type` 的值，來源 **重複項目**
- **如果**「辭典值」**是** `audio`：
  - **儲存檔案**（Save File）：檔案選 **URL 的內容**，關閉「詢問儲存位置」，子路徑填 `MediaHook/`
- **否則**：
  - **儲存到相簿**（Save to Photo Album）：選 **URL 的內容**，相簿選「最近項目」
- **結束如果**
- **結束重複**

**⑩ 取得辭典值**：取得 `caption` 的值，來源 **回應**

**⑪ 如果**「辭典值」**有任何值**：
- **取得辭典值**：取得 `share_text` 的值，來源 **回應**
- **拷貝到剪貼板**（Copy to Clipboard）
- **結束如果**

**⑫ 取得辭典值**：取得 `message` 的值，來源 **回應**

**⑬ 顯示通知**（Show Notification）：內容為上一步的「辭典值」

完成。第一次執行時，iOS 會詢問是否允許連線到 `dl.gyke.net`、是否允許存取照片，選 **永遠允許**。

## 建立「MediaHook 抽音訊」

1. 在捷徑列表長按「MediaHook 下載」→ **複製**，改名為「MediaHook 抽音訊」。
2. 把步驟 ③ 的 `mode` 從 `auto` 改成 `audio`。
3. （可選）步驟 ⑩、⑪ 的文案拷貝可以刪掉。

音訊會存到「檔案」App →「iCloud 雲碟」→「Shortcuts」→「MediaHook」。

## 使用方式

- 在 IG、X、TikTok、FB、小紅書、抖音按 **分享** → 找到「MediaHook 下載」。
  第一次可能要在分享選單最右邊的「更多」裡把它加到常用。
- 也可以先 **拷貝連結**，再到主畫面或小工具直接點捷徑。

## 常見狀況

| 看到的訊息 | 原因 |
|---|---|
| API 金鑰錯誤 | 步驟 ① 的金鑰打錯，或 `Bearer` 後面少了空格 |
| 不支援這個網站 | 目前只支援 IG、Threads、X、TikTok、FB、小紅書、抖音 |
| 需要登入／cookies 可能已失效 | VPS 上沒有該平台的 cookies，或已過期（見 [deploy.md](deploy.md)） |
| 處理中… | 超過 5 分鐘還沒下載完（通常是很長的影片），稍後再試一次 |
| 存到相簿失敗 | 「設定」→「捷徑」→ 確認允許存取照片 |
